# `vrbm‑AI` Docs

Welcome to the official documentation for `vrbm‑AI`, a lightweight Python wrapper that turns Ollama into a strict, type‑validated Python literal generator.

`vrbm‑AI` ensures that model outputs are always valid Python values — strings, ints, floats, lists, dicts, tuples, etc. If the model returns invalid output, `vrbm‑AI` automatically retries up to three times.
